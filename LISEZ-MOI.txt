MON COACH FITNESS — V10 CORRIGÉE

Corrections :
- Restaure les exercices officiels absents de la liste enregistrée dans le navigateur, sans remplacer les exercices existants ni supprimer les exercices personnalisés.
- Après « Enregistrer la séance », ouvre automatiquement « Mes progrès » pour afficher l'historique actualisé.

Installation :
1. Faites d'abord un export des données depuis « Mes progrès ».
2. Décompressez ce ZIP.
3. Remplacez les fichiers du dépôt GitHub par ceux du ZIP, notamment index.html, service-worker.js, manifest.webmanifest et les icônes.
4. Validez les changements (Commit changes) et attendez la fin de GitHub Pages.
5. Fermez les anciens onglets du site, puis rouvrez-le. Les données sont conservées localement dans le navigateur ; l'export préalable est recommandé.
