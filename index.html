📲 Sur Android

Pour l’installer avec une icône : le dossier PWA fourni contient les fichiers de l’application. Il faut d’abord l’héberger sur une adresse HTTPS (par exemple via GitHub Pages ou Netlify), puis ouvrir cette adresse dans Chrome Android et choisir ⋮ → Ajouter à l’écran d’accueil ou Installer l’application. Un fichier HTML ou ZIP ne s’installe pas comme un APK natif.
